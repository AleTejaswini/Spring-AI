# Spring AI with Ollama and Llama 3.2

This project is a hands-on implementation of Generative AI concepts using Java, Spring Boot, Spring AI, Ollama, and Llama 3.2.

The project focuses on understanding how AI capabilities can be integrated into Java applications.

## Concepts Implemented

* ChatClient and LLM integration
* Prompt Templates
* Structured Output
* Embeddings
* Cosine Similarity
* Semantic Search
* Vector Store
* RAG (Retrieval-Augmented Generation)
* Function Calling

## Practical Features

Travel Guide Generator

Cuisine Helper

Semantic Job Search

Product RAG Application

Stock Function Calling

## Technologies Used

Java 21

Spring Boot

Spring AI

Ollama

Llama 3.2

Maven

Thymeleaf

## Setup

Install Ollama and pull the Llama 3.2 model.

```bash
ollama pull llama3.2
```

Clone the repository and run the Spring Boot application.

```bash
mvn clean install
mvn spring-boot:run
```
